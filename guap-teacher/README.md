# guap-teacher — плагин ZCode

Плагин подключает MCP-сервер **guap-teacher** — движок автоматизации
преподавательской стороны [pro.guap.ru](https://pro.guap.ru) (Личный кабинет
ГУАП): списки отчётов на проверку, карточки заданий с матрицей «студенты ×
отчёты», дисциплины, ведомости «Список группы», материалы, объявления,
расписание. Плагин живёт в этом же репозитории (каталог `guap-teacher/`);
сам репозиторий — локальный маркетплейс ZCode (`marketplace.json` в корне).

Навыков внутри плагина **нет намеренно**: методология (чек-листы ревью,
правила приёмки, критерии оценивания) живёт в личных копиях преподавателя
`~/.agents/skills/guap-*/SKILL.md` — ZCode читает этот каталог нативно, а
обновления движка личные копии не затрагивают.

## Первый шаг после установки (инструкция для агента)

Выполни от имени преподавателя:

```
uv --directory C:/Users/MADTeacher/Documents/GitHub/guap-teacher-mcp run guap-teacher init
```

Команда сеет канонические навыки `guap-*` в `~/.agents/skills/`
(существующие файлы не перезаписывает), печатает сводку и сниппеты
MCP-конфига для ZCode / Codex / Qwen Code. После этого навыки доступны
агенту автоматически; MCP-инструменты (`check_auth_status`,
`list_reports`, …) — после перезапуска сессии ZCode.

Дальше преподаватель настраивает правила под себя разговором:
«в моих отчётах титульный лист не проверяй, зато ругай за отсутствие
тестов» → агент правит `~/.agents/skills/guap-review/SKILL.md`.
Сравнить личные копии с каноном: `guap-teacher skills diff`.

## Конфигурация MCP

Манифест `.zcode-plugin/plugin.json` запускает сервер через uvx прямо
из GitHub (репозиторий публичный — иначе uvx-установка не работает):

```json
"mcpServers": {
  "guap-teacher": {
    "command": "uvx",
    "args": [
      "--from",
      "git+https://github.com/MADTeacher/guap-teacher-mcp",
      "guap-teacher"
    ]
  }
}
```

Тот же путь зашит в константе `PACKAGE_SOURCE` в
`src/guap_teacher_mcp/cli.py` и в командах в README основного
репозитория. Для разработки удобнее локальный клон:
`uv --directory <путь к guap-teacher-mcp> run guap-teacher` — например,
прямым подключением в настройках ZCode; тогда плагинное подключение
стоит отключить, чтобы сервер не дублировался.

## Замечания

- Если guap-teacher уже подключён в ZCode напрямую (секция mcpServers
  настроек) — оставьте только одно подключение, иначе сервер задублируется.
- Обновление движка: `uvx --refresh --from git+https://github.com/MADTeacher/guap-teacher-mcp guap-teacher --help`;
  для разработки — `git pull` в клоне.
- Вход в портал — всегда руками преподавателя через SSO
  (`authenticate`); креды нигде не хранятся.
